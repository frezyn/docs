`GET /v1/quote` returns the current exchange rate (yuan per BRL) used by noob-exchange for all payment and withdrawal conversions. The rate is refreshed in real time and is the same rate applied when you create a payment or withdrawal.

## Request

```bash
curl https://api.noob.exchange/v1/quote \
  -H "Authorization: Bearer nox_your_key_here"
```

## Response

<ResponseField name="quote" type="number">
  Current exchange rate expressed as yuan per BRL. For example, a value of `1.2` means 1 yuan costs 0.833 BRL — the payer sends 0.833 BRL for every 1 yuan you receive.
</ResponseField>

**Example response**

```json
{
  "quote": 1.2
}
```

## Errors

| HTTP Status | Error Code | Description |
|-------------|------------|-------------|
| `401` | `unauthorized` | Missing or invalid Bearer token. |
| `403` | `developer_required` | Your account does not have developer access enabled. |
| `403` | `account_not_verified` | Your account has not completed identity verification. |
| `500` | `internal` | An unexpected server-side error occurred. |

`GET /v1/withdrawals` returns up to 50 of the most recent withdrawal requests for your account, ordered from newest to oldest. Use the `status` field on each entry to track pending and completed transfers.

## Request

```bash
curl https://api.noob.exchange/v1/withdrawals \
  -H "Authorization: Bearer nox_your_key_here"
```

## Response (200 OK)

The response is a JSON array of withdrawal objects. Each object contains the following fields:

<ResponseField name="id" type="string (uuid)">
  Unique identifier for the withdrawal request.
</ResponseField>

<ResponseField name="yuan_value" type="number">
  Yuan amount that was reserved and converted for this withdrawal.
</ResponseField>

<ResponseField name="value_real" type="number">
  BRL amount sent (or to be sent) to the PIX key, based on the frozen `quote`.
</ResponseField>

<ResponseField name="quote" type="number">
  Exchange rate (yuan per BRL) frozen at the time the withdrawal was requested.
</ResponseField>

<ResponseField name="pix_key" type="string">
  PIX key that received or will receive the BRL transfer.
</ResponseField>

<ResponseField name="status" type="string">
  Current withdrawal status. One of `pending`, `paid`, or `rejected`.
</ResponseField>

<ResponseField name="created_at" type="string (datetime)">
  ISO 8601 timestamp of when the withdrawal request was submitted.
</ResponseField>

<ResponseField name="processed_at" type="string (datetime)">
  ISO 8601 timestamp of when the withdrawal was processed (paid or rejected). Only present once the withdrawal has been actioned.
</ResponseField>

**Example response**

```json
[
  {
    "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "yuan_value": 50,
    "value_real": 41.67,
    "quote": 1.2,
    "pix_key": "user@example.com",
    "status": "paid",
    "created_at": "2024-06-01T14:00:00Z",
    "processed_at": "2024-06-01T14:35:22Z"
  },
  {
    "id": "b2c3d4e5-f6a7-8901-bcde-f12345678901",
    "yuan_value": 20,
    "value_real": 16.67,
    "quote": 1.2,
    "pix_key": "user@example.com",
    "status": "pending",
    "created_at": "2024-06-01T16:10:00Z"
  }
]
```

## Errors

| HTTP Status | Error Code | Description |
|-------------|------------|-------------|
| `401` | `unauthorized` | Missing or invalid Bearer token. |
| `403` | `developer_required` | Your account does not have developer access enabled. |
| `500` | `internal` | An unexpected server-side error occurred. |

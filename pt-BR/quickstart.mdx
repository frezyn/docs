title: "noob-exchange Quickstart: Do Primeiro Pagamento ao Saque"
sidebarTitle: "Quickstart"
description: "Crie seu primeiro pagamento PIX, acompanhe o status e saque seu saldo em yuan para uma chave PIX usando a API do noob-exchange em minutos."
---

Este quickstart percorre o ciclo completo de pagamento usando a API do noob-exchange: buscar a cotação de câmbio atual, gerar uma cobrança PIX, confirmar o pagamento e sacar seu saldo em yuan para uma chave PIX. Cada etapa se baseia na anterior — siga-as em ordem.

<Steps>
  <Step title="Obtenha Sua Chave de API">
    Toda requisição exige uma chave de API válida `nox_...` passada como token Bearer. Se você ainda não criou uma, consulte a página de [Autenticação](/pt-BR/authentication) para instruções passo a passo.

    Defina sua chave como variável de ambiente para reutilizá-la em todos os exemplos abaixo:

    ```bash
    export NOX_KEY="nox_sua_chave_aqui"
    ```
  </Step>

  <Step title="Confira a Cotação Atual">
    Antes de criar um pagamento, busque a cotação de câmbio em tempo real entre BRL e yuan. A cotação retornada aqui é a mesma taxa que será travada quando você criar uma cobrança.

    ```bash
    curl https://api.noob.exchange/v1/quote \
      -H "Authorization: Bearer $NOX_KEY"
    ```

    **Resposta:**

    ```json
    {
      "quote": 1.2
    }
    ```

    Neste exemplo, cada 1 BRL é convertido em 1,2 yuan.
  </Step>

  <Step title="Crie um Pagamento">
    Envie uma nova cobrança PIX especificando o valor em yuan. O noob-exchange trava a cotação atual, gera um QR code e uma chave PIX para o pagador e retorna o crédito esperado em yuan.

    ```bash
    curl -X POST https://api.noob.exchange/v1/payments \
      -H "Authorization: Bearer $NOX_KEY" \
      -H "Content-Type: application/json" \
      -d '{"value": 100}'
    ```

    **Resposta:**

    ```json
    {
      "payment_id": "pay_a1b2c3d4e5",
      "qrcode": "00020126...",
      "pix_key": "pix@noob.exchange",
      "amount_real": 100.00,
      "yuan_value": 120.00,
      "quote": 1.2,
      "status": "pending",
      "expires_at": "2024-08-01T15:10:00Z"
    }
    ```

    Entregue o `qrcode` ou o `pix_key` ao pagador. Assim que ele concluir a transferência, o status do pagamento é atualizado automaticamente.

    <Tip>
      A cobrança expira em 10 minutos. Garanta que o pagador conclua o pagamento dentro desse prazo — após `expires_at`, a cobrança não pode mais ser quitada e uma nova precisa ser criada.
    </Tip>
  </Step>

  <Step title="Verifique o Status do Pagamento">
    Consulte o endpoint de pagamento com o `payment_id` para confirmar que o pagador concluiu a transferência.

    ```bash
    curl https://api.noob.exchange/v1/payments/pay_a1b2c3d4e5 \
      -H "Authorization: Bearer $NOX_KEY"
    ```

    **Resposta:**

    ```json
    {
      "payment_id": "pay_a1b2c3d4e5",
      "status": "paid",
      "amount_real": 100.00,
      "yuan_value": 120.00,
      "quote": 1.2,
      "paid_at": "2024-08-01T15:07:43Z"
    }
    ```

    Quando o `status` for `paid`, o `yuan_value` correspondente foi creditado no seu saldo e está disponível para saque. Outros status possíveis são `pending`, `cancelled` e `expired`.
  </Step>

  <Step title="Saque Seu Saldo">
    Saque yuan do seu saldo para qualquer chave PIX válida. Especifique o valor em yuan e a chave PIX de destino (CPF, CNPJ, telefone, e-mail ou chave aleatória).

    ```bash
    curl -X POST https://api.noob.exchange/v1/withdrawals \
      -H "Authorization: Bearer $NOX_KEY" \
      -H "Content-Type: application/json" \
      -d '{"yuan_value": 50, "pix_key": "user@example.com"}'
    ```

    **Resposta:**

    ```json
    {
      "withdrawal_id": "wth_z9y8x7w6v5",
      "pix_key": "user@example.com",
      "yuan_value": 50.00,
      "amount_real": 41.67,
      "quote": 1.2,
      "status": "pending",
      "created_at": "2024-08-01T15:12:00Z"
    }
    ```

    O saque entra na fila para processamento. O equivalente em BRL é calculado usando a cotação vigente no momento da requisição de saque. Os status possíveis são `pending`, `paid` e `rejected`.
  </Step>
</Steps>
